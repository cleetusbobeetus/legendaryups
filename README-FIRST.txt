LEGENDARY UPS - CLEAN PAPER PARKOUR TEST SERVER
Minecraft Java Edition 1.21.10

1. Extract this ZIP (do not run from inside the ZIP).
2. Double-click START-SERVER.bat. It checks Java and downloads an official Paper 1.21.10 server JAR if paper.jar is missing.
   Requires internet for first launch. If automatic download fails, download Paper 1.21.10 from https://papermc.io/downloads/paper and place it here as paper.jar.
3. On first launch the server will stop to ask for EULA acceptance.
   Read https://aka.ms/MinecraftEULA . If you agree, edit eula.txt and change eula=false to eula=true.
4. Double-click START-SERVER.bat again. Wait for 'Done'.
5. Place your parkour datapack ZIP in datapacks-to-install (DO NOT extract it unless its instructions require that).
6. Type 'stop' in the server console, then double-click START-SERVER.bat to restart. It automatically copies ZIP datapacks into world/datapacks.
7. In Minecraft Java 1.21.10: Multiplayer > Direct Connection > localhost:25566.

For multiplayer beyond your PC, configure your firewall/router separately. Server binds to all interfaces by default; keep it private while testing.

Datapack commands:
  datapack list
  reload
  function <namespace>:<name>  (only if your datapack provides that function)

This folder is a CLEAN SERVER: no old worlds, plugins, or datapacks included.
If your parkour download is a WORLD ZIP rather than a datapack, do NOT put it in datapacks-to-install. Ask for help importing it as a world instead.
If the first startup does not create world/datapacks, let it complete world generation before installing.
